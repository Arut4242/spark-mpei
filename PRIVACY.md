# Политика конфиденциальности (Privacy Policy)

**Дата последнего обновления:** Ноябрь 2026 г.  
**Проект:** Spark MPEI (`ru.mpei.assistant`)  
**Статус:** Неофициальное независимое приложение для студентов НИУ «МЭИ». Не аффилировано с ФГБОУ ВО «НИУ «МЭИ»».

---

## 1. Общие принципы

Приложение Spark разработано по концепции **Local-First** («всё на устройстве»). Приложение не использует собственных серверов, промежуточных прокси, бэкендов разработчика, аналитических метрик или рекламных трекеров. Все сетевые соединения выполняются напрямую между вашим мобильным устройством и официальными информационными системами.

## 2. Какие данные обрабатываются и где они хранятся

### 2.1. Учётные данные и пароли
* **Сессия БАРС:** Cookie-файлы авторизации веб-кабинета БАРС.
* **Почта ОСЭП МЭИ:** Логин и пароль от студенческого почтового ящика (`@mpei.ru`).
* **Хранение:** Хранятся **исключительно локально** на устройстве в защищённом хранилище Android Keystore с использованием библиотеки `androidx.security.crypto:security-crypto` (алгоритмы шифрования `AES-256-GCM` для значений и `AES-256-SIV` для ключей). Хранение паролей в незашифрованном виде полностью исключено.

### 2.2. Учебные данные и почта
* **Полное шифрование базы данных (SQLCipher):** Вся локальная база данных SQLite (`mpei_assistant.db`) защищена полностраничным шифрованием **SQLCipher (AES-256)**. Криптографический ключ базы данных генерируется с помощью криптостойкого ГСЧ (`SecureRandom`) и сохраняется в аппаратном `Android Keystore` через `EncryptedSharedPreferences`. Любое прямое извлечение файла базы данных без аппаратного ключа устройства невозможно.
* **Оценки и баллы КМ:** Загружаются из личного кабинета БАРС и сохраняются в зашифрованной локальной базе данных SQLite. Подробные списки контрольных мероприятий и баллы дополнительно защищены на уровне полей аппаратным ключом Android Keystore (AES-256 GCM).
* **Посещаемость и пропуски:** Загружаются из электронного журнала БАРС и хранятся в защищённой базе данных.
* **Расписание занятий:** Кэшируется локально на устройстве для выбранной группы или преподавателя.
* **Письма студенческой почты:** Заголовки, тексты и HTML-тела писем сохраняются во внутреннем зашифрованном хранилище приложения с дополнительным шифрованием тел (AES-256 GCM). Для минимизации чувствительного кэша приложение автоматически ротирует и удаляет тела устаревших писем.
* **Полная очистка при выходе (Logout):** При выходе из учётной записи БАРС или почты ОСЭП соответствующие данные (оценки, пропуски, письма) немедленно удаляются из базы Room, сессионные cookie удаляются из WebView с последующим сбросом, а все скачанные почтовые вложения рекурсивно удаляются из кэша приложения.

### 2.3. Диагностические логи
* Для анализа ошибок приложение ведёт локальный кольцевой журнал событий (`spark_debug.log`).
* Размер файла журнала строго ограничен (не более 512 КБ с автоматической ротацией).
* Все персональные данные перед записью в лог проходят автоматическое маскирование:
  * ФИО студентов и преподавателей маскируются;
  * Адреса электронной почты скрываются (`***@mpei.ru`);
  * Логины, пароли и сессионные cookie скрываются (`[СКРЫТО]`);
  * Идентификаторы студентов (UUID / studentID) маскируются;
  * URL-адреса очищаются от query-параметров (`?[ПАРАМЕТРЫ_СКРЫТЫ]`).
* Логи никогда не отправляются автоматически. Отправка возможна исключительно по явному решению пользователя через стандартное системное меню «Поделиться».

## 3. Сетевые взаимодействия

Приложение отправляет запросы строго по следующим адресам:
1. **`https://bars.mpei.ru`** (HTTPS, порт 443) — получение данных балльно-рейтинговой системы и журнала посещаемости. Сессионные cookie изолированы в доменной области `bars.mpei.ru` с флагами `secure` и `httpOnly`. Окно входа в БАРС использует строгий allowlist официальных доменов (`*.mpei.ru`) и блокирует любые внешние переходы.
2. **`mail.mpei.ru`** (IMAPS, порт 993) — защищённое соединение с почтовым сервером ОСЭП МЭИ с валидацией всей криптографической цепочки встроенных официальных сертификатов НИУ «МЭИ» (корневой удостоверяющий центр `CN=MPEI (TU)` и выпускающий центр `CN=public-PUBLICCA-CA`) и проверкой подлинности сервера (`mail.imaps.ssl.checkserveridentity = true`).
3. **`https://ts.mpei.ru` / сервисы расписания** (HTTPS) — загрузка публичной сетки занятий.
4. **`https://api.github.com`** (HTTPS) — проверка наличия новых релизов приложения в официальном репозитории. Скачивание новой версии происходит через браузер по официальной ссылке релиза на GitHub.

В почтовом клиенте включена блокировка автоматической загрузки удалённых изображений (`blockNetworkImage = true`) для защиты от отслеживающих веб-маяков.
