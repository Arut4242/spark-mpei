# Политика конфиденциальности (Privacy Policy)

**Дата последнего обновления:** Ноябрь 2026 г.  
**Проект:** Spark MPEI (`ru.mpei.assistant`)  
**Статус:** Неофициальное независимое приложение для студентов НИУ «МЭИ». Не аффилировано с ФГБОУ ВО «НИУ «МЭИ»».

---

## 1. Общие принципы

Приложение Spark разработано по концепции **Local-First** («всё на устройстве»). Приложение не использует собственных серверов, промежуточных прокси, бэкендов разработчика, аналитических метрик или рекламных трекеров. Все сетевые соединения выполняются напрямую между вашим мобильным устройством и официальными информационными системами.

---

## 2. Какие данные обрабатываются и где они хранятся

### 2.1. Учётные данные и пароли
* **Сессия БАРС:** Cookie-файлы авторизации веб-кабинета БАРС.
* **Почта ОСЭП МЭИ:** Логин и пароль от студенческого почтового ящика (`@mpei.ru`).
* **Хранение:** Хранятся **исключительно локально** на устройстве в защищённом хранилище Android Keystore с использованием библиотеки `androidx.security.crypto:security-crypto` (алгоритмы шифрования `AES-256-GCM` для значений и `AES-256-SIV` для ключей). Хранение паролей в незашифрованном виде полностью исключено.

### 2.2. Учебные данные
* **Оценки и баллы КМ:** Загружаются из личного кабинета БАРС и кэшируются в локальной базе данных SQLite (Room) на устройстве для офлайн-доступа.
* **Посещаемость и пропуски:** Загружаются из электронного журнала БАРС и хранятся локально в базе данных.
* **Расписание занятий:** Кэшируется локально на устройстве для выбранной группы или преподавателя.
* **Письма студенческой почты:** Заголовки, тексты и вложения сохраняются во внутренней памяти приложения.

### 2.3. Диагностические логи
* Для анализа ошибок приложение ведёт локальный кольцевой журнал событий (`spark_debug.log`).
* Размер файла журнала строго ограничен (не более 512 КБ с автоматической ротацией).
* Все персональные данные перед записью в лог проходят автоматическое маскирование:
  * ФИО студентов и преподавателей маскируются;
  * Адреса электронной почты скрываются (`***@mpei.ru`);
  * Логины, пароли и сессионные cookie скрываются (`[СКРЫТО]`);
  * Идентификаторы студентов (UUID / studentID) маскируются;
  * URL-адреса очищаются от query-параметров (`?[ПАРАМЕТРЫ_СКРЫТЫ]`).
* Логи никогда не отправляются автоматически. Отправка возможна исключительно по явному решению пользователя через стандартное системное меню «Поделиться».

## 3. Сетевые взаимодействия

Приложение отправляет запросы строго по следующим адресам:
1. **`https://bars.mpei.ru`** (HTTPS, порт 443) — получение данных балльно-рейтинговой системы и журнала посещаемости. Клиент строго отклоняет любые запросы к сторонним хостам.
2. **`mail.mpei.ru`** (IMAPS, порт 993) — защищённое соединение с почтовым сервером ОСЭП МЭИ с обязательной проверкой TLS-сертификата и подлинности сервера (`mail.imaps.ssl.checkserveridentity = true`).
3. **`https://mpei.space` / сервисы расписания** (HTTPS) — загрузка публичной сетки занятий.
4. **`https://api.github.com`** (HTTPS) — проверка наличия новых релизов приложения в официальном репозитории. Перед установкой обновления проверяются цифровая подпись APK и контрольная сумма.

В почтовом клиенте включена блокировка автоматической загрузки удалённых изображений (`blockNetworkImage = true`) для защиты от отслеживающих веб-маяков.
