# ⚡ Spark — Помощник студента НИУ «МЭИ»

Современный, быстрый и полностью автономный Android-клиент для студентов Национального исследовательского университета «МЭИ». Разработан на **Jetpack Compose** в дизайне Apple HIG и работает по принципу **Local-First** (все данные хранятся локально на устройстве).

---

## 🚀 Основные возможности

### 📅 Расписание занятий
- Полная сетка пар на весь семестр с офлайн-доступом
- Свайп по дням и неделям с нумерацией по БАРС
- Интерактивный прогресс-бар текущей пары (с учётом 5-минутного внутрипарного перерыва)
- Карточка обеденного перерыва с таймером
- Быстрый поиск и переключение между любыми группами института

### 🎓 БАРС (Балльно-рейтинговая система)
- Отображение контрольных мероприятий (КМ), баллов и итоговых оценок
- Умный калькулятор прогноза оценок с учётом весов КМ и возможных пересдач
- Отслеживание академических задолженностей

### 🚫 Пропуски и допуск к автомату (Правило 6,25%)
- Мониторинг пропусков напрямую из журнала посещаемости БАРС
- Расчёт допустимого лимита пропусков без уважительной причины (не более 6,25% аудиторных пар)
- Корректная обработка дисциплин с зачётом по совокупности

### ✉️ Почта ОСЭП МЭИ (`mail.mpei.ru`)
- Встроенный почтовый клиент для студенческой почты
- Просмотр и скачивание учебных материалов и вложений (PDF, DOCX, архивы)
- Уведомления о новых письмах от преподавателей

### 🔄 Встроенное автообновление
- Автоматическая проверка новых релизов через GitHub Releases при запуске
- Скачивание и установка свежей версии прямо внутри приложения в 1 клик

---

## 🔒 Безопасность и приватность
- **Local-First:** приложение не использует никаких сторонних серверов — запросы идут напрямую к официальным сервисам МЭИ (`bars.mpei.ru`, `mail.mpei.ru`, `mpei.ru`).
- Все пароли и токены шифруются с помощью аппаратного ключа Android (`EncryptedSharedPreferences`).
